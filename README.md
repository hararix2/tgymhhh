# عِدّة | سجل التمرين المحلي

تطبيق عربي لتسجيل مجموعات التمرين ومؤقّت الراحة، مع تسجيل الدخول بالبريد الإلكتروني عبر Supabase Auth.

## التشغيل

1. ثبّت Node.js 18 أو أحدث وأنشئ مشروعًا في Supabase.
2. فعّل مزوّد Email في إعدادات Authentication، واضبط Site URL على `http://127.0.0.1:3000`.
3. افتح SQL Editor في Supabase وشغّل محتوى [`supabase-schema.sql`](supabase-schema.sql) لإنشاء جدول المجموعات وسياسات RLS.
4. انسخ Project URL ومفتاح `publishable` أو `anon` من إعدادات API في Supabase.
5. افتح PowerShell في مجلد المشروع، ثم عيّن المتغيرات وشغّل الخادم:

   ```powershell
   $env:SUPABASE_URL = "https://YOUR_PROJECT.supabase.co"
   $env:SUPABASE_ANON_KEY = "YOUR_PUBLISHABLE_OR_ANON_KEY"
   node server.js
   ```

6. افتح <http://127.0.0.1:3000> وأنشئ حسابًا أو سجّل الدخول، أو تابع كضيف دون حساب. إذا كان تأكيد البريد مفعّلًا في Supabase، أكّد البريد قبل تسجيل الدخول.

لتغيير المنفذ في PowerShell، اضبطه قبل تشغيل الخادم:

```powershell
$env:PORT=3001; node server.js
```

## البيانات والخصوصية

- تُحفظ بيانات الجلسات في `data/workouts.json`، بينما تُحفظ المجموعات الجديدة في جدول `public.workout_sets` في Supabase.
- يحفظ وضع الضيف الجلسات والمجموعات في التخزين المحلي للمتصفح على الجهاز الحالي فقط؛ لا تُرسل بيانات الضيف إلى Supabase ولا تظهر لحساب مسجّل.
- يتحقق الخادم من رمز Supabase Auth، ويتأكد من ملكية الجلسة قبل تعديلها. تحصر سياسات RLS قراءة المجموعات وإضافتها وحذفها في المستخدم صاحب `auth.uid()`.
- تبقى المجموعات المحلية الأقدم في ملف JSON وتظهر بجانب المجموعات المخزنة في Supabase؛ المجموعات القديمة غير المعيّنة لحساب لا تُعرض لحساب جديد.
- حالة المؤقّت محفوظة في التخزين المحلي للمتصفح، ويستمر حساب الوقت بعد تحديث الصفحة.
- الخادم مربوط بـ`127.0.0.1` حتى لا يُتاح على الشبكة المحلية.
- لا تضع مفتاح `service_role` أو مفتاحًا سريًا في `SUPABASE_ANON_KEY`. يستخدم التطبيق مفتاح `publishable` أو `anon` العام فقط.
- يحتاج تسجيل الدخول إلى اتصال بالإنترنت لتحميل Supabase JS والتحقق من الحساب. خط Google Fonts اختياري؛ عند انقطاع الإنترنت يستخدم المتصفح خطًا بديلًا.

يتطلب تشغيل التطبيق وجود Node.js وإعداد متغيرات Supabase على الجهاز. لا يحتاج إلى `npm install`.
